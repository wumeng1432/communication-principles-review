# 通信原理 · 期末复习站

面向 **中南民族大学 电子信息工程学院**《通信原理》期末考试的复习网站。

以 **樊昌信、曹丽娜《通信原理》（第7版，国防工业出版社）** 的 13 章体系为骨架，
结合公开试卷的题型结构与高频考点整理而成。

## 在线访问

> 部署后填写 GitHub Pages 地址

## 内容结构

| 模块 | 说明 |
|---|---|
| **首页** | 复习进度追踪、快速入口、五步复习路线、13 章速览 |
| **民大考情与重点** | 题型分值分布、13 章考频权重、复习策略、高频失分点 |
| **教材精讲（13 章）** | 每章含考点框架、核心公式、必背概念、典型例题（可展开解析）、易错提醒 |
| **公式速查表** | 36 条核心公式，支持关键词搜索，可跳转对应章节 |
| **模拟考试（3 套）** | 选择题即时判分，填空／简答／计算题附完整解题步骤 |
| **速记手册** | 记忆口诀、4 张对比表、易错点清单、考场答题建议 |

## 技术说明

- 纯静态，**零外部依赖**（公式用 Unicode 字符渲染，不依赖 KaTeX／CDN，断网可用）
- 单页应用，hash 路由
- 复习进度与模拟卷成绩保存在浏览器 `localStorage`
- 响应式布局，支持手机访问

## 文件结构

```
index.html   主页面（结构 + 样式 + 路由挂载）
data.js      13 章教材精讲内容数据
exam.js      考情分析、公式库、速记数据、3 套模拟卷
app.js       路由与渲染逻辑
```
